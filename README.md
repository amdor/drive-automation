# Get started

(Create venv): `python3 -m venv dev` \
Start the venv: `. dev/bin/activate` \
(install dependencies: `pip install -r requirements.txt`)

## For usage of scripts requiring Drive connection

token.json is autogenerated, credentials.json must be generated as per instructed on [Google documentation](https://developers.google.com/workspace/drive/api/quickstart/python#authorize_credentials_for_a_desktop_application) \

Add credentials.json to the project root. (add permissions in Drive to the account you generated credentials for).

# local_sorter.py

Has one config folder_path, this is the target folder locally where sorting should happen. \
The script takes all files in `folder_path` and puts them into a folder by the month each file was created. \
So a file created at 2025.01.20 goes to folder `1`. \
Folders 1-12 are automatically created.

# uploader.py

`folder_path` the path locally to look for files and folder in for \
`drive_folder_id` the drive root folder ID (the last part of the URL opening the target folder) \
Uploads all files and folders from `folder_path` to `drive_folder_id`, recursively.

# file_sorter.py

Sorts files of your drive folders by their creation month. \
`foldersToCheck` drive folder IDs to sort files from(the last part of the URL opening the target folder is the ID) \
`sortConfig`:
 - `type`: "months" we only sort by months for now. creation date's month will be the folder name the file is put in
 - `targetFolderId`: drive folder ID to put files (and sorting folders) into

# recoverer.py

Recovers files to their first version, so the version at upload.
